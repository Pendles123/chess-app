# Full-Stack Chess Application

A full-stack chess application built with Java, Spring Boot and React. The project combines backend chess-game logic and RESTful APIs with a browser-based React user interface.

## Features

- Java-based chess game logic and board-state management
- Move validation for chess pieces
- REST API endpoints to start a game, make moves, agree a draw and resign
- React interface for interacting with the chessboard
- JUnit 5 tests covering core backend logic

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Maven
- REST APIs
- JUnit 5

### Frontend
- React
- Vite
- JavaScript
- HTML and CSS
